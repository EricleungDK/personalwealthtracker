# Learn Category Memory From Review Workbook

## Parent

[PRD: Manual Review Workbook And Category Feedback Loop](./2026-05-16-prd-manual-review-workbook-and-category-feedback-loop.md)

## What To Build

Extend Category Memory learning so the existing learning command can import the reviewed XLSX artifact directly. Learning should remain separate from workbook commit and should only generalize explicit opt-in decisions for learnable workbook fields.

## Acceptance Criteria

- [x] `learn-category-memory` accepts reviewed XLSX artifacts generated by the monthly dry run.
- [x] Existing reviewed CSV import behavior remains supported.
- [x] Rows with blank `manual_category` are skipped.
- [x] Rows with `manual_category` filled and blank or `no` `learn_to_memory` are not learned into Category Memory.
- [x] Rows with `manual_category` filled and `learn_to_memory=yes` are learned only when the selected field is learnable.
- [x] Learnable fields are workbook rows that exist and are not derived or fixed.
- [x] Attempts to learn derived, fixed, or otherwise non-learnable workbook fields are warned and skipped without corrupting memory.
- [x] Learned mappings use normalized merchant identity and preserve existing upsert behavior.
- [x] Optional recurring hint fields remain supported where present.
- [x] Import results report imported, skipped-unlearned, and skipped-non-learnable counts.
- [x] Tests cover XLSX import, opt-in learning, blank/no behavior, non-learnable validation, existing memory preservation, and existing CSV compatibility.

## Blocked By

None - can start immediately.
